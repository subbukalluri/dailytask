# Daily Task

A daily Java practice repository, organized by week and day.

## Week 1: Core Java Basics

Setup, variables, data types, operators, type casting, conditionals, and simple calculators
(area formulas, simple interest, temperature conversion, grade calculator, and more).

## Week 2: Loops and Number Logic

- **Day 1**: For loop basics, sum of N numbers, multiplication table.
- **Day 2**: While loop practice, factorial (for vs. while), reverse a number, sum of digits.
- **Day 3**: Palindrome number, Armstrong number, prime number check, Fibonacci series.
- **Day 4**: Nested-loop patterns — right triangle, inverted triangle, number pattern, alphabet pattern.
- **Day 5**: Primes in a range, even/odd count in a range, a logic revision set (sum of squares, GCD, digit count).

## Structure

Each task lives in its own folder: `weekN/dayM-task-name/TaskClassName.java`.
