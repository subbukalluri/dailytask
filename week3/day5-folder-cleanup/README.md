# Week 3 Folder Cleanup

Every Week 3 task lives in its own folder named `dayN-task-name`, holding only
the `.java` source for that task. No `.class` files, no duplicate copies, and
no unused files are kept.

## Cleanup rules followed
- One folder per task, one clearly named class per file (class name = file name).
- Practice sets hold three separate, descriptively named programs.
- Compiled `.class` files are ignored through the root `.gitignore`.
