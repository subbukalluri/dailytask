# Week 3: Methods and Arrays

## Concepts learned
- **Methods**: `static` methods with and without return values, called from `main`.
- **Parameters**: passing values in and getting results back.
- **Method overloading**: same name, different parameter types or counts.
- **Arrays**: declaring, reading input into, and looping over `int[]`.
- **Array algorithms**: sum and average, max and min, linear search, reverse, bubble sort, second largest, duplicates.
- **Reusable code**: utility method classes and menu-driven console programs.
- **Clean code**: meaningful method names, comments, and organised folders.
