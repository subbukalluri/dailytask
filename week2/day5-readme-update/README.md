# Week 2 Summary: Loops and Number Logic

This folder's task was to summarize the Week 2 topics in the repository README (see the root `README.md`).

## Topics covered this week

- **For loops**: ascending/descending counting, sum of N numbers, multiplication tables.
- **While loops**: counting and countdown patterns, factorial (compared against the for-loop version).
- **Digit manipulation**: reversing a number and summing its digits using modulus (`%`) and integer division (`/`).
- **Number logic checks**: palindrome numbers, Armstrong numbers, and prime number checks.
- **Series generation**: Fibonacci series for n terms.
- **Nested loops / patterns**: right triangle, inverted triangle, number pattern (1, 12, 123, 1234), alphabet pattern (A, AB, ABC).
- **Range-based problems**: listing primes in a range, counting even/odd numbers in a range.
- **Logic revision**: sum of squares, greatest common divisor (GCD), and digit counting.

Each task lives in its own `week2/dayN-task-name` folder, consistent with the Week 1 structure.
