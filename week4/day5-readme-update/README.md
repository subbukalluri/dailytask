# Week 4: Strings and Object-Oriented Programming

## Topics covered
- **Weekly Test**: methods, arrays, searching, sorting, and array-based logic.
- **Strings**: reverse, palindrome, vowels and consonants, character frequency, removing spaces, word count, and comparison with `equals`, `equalsIgnoreCase`, and `compareTo`.
- **Classes and objects**: fields, creating objects, and using `new`.
- **Constructors**: default and parameterized, with `this`.
- **Methods inside a class**: displaying and updating object data.
- **Encapsulation**: private fields with getters and setters, plus validation in setters.
- **Mini application**: a menu-driven student management console app.
